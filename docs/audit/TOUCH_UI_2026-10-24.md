## 行为

| 状态 | 原放映退出按钮 | 上下翻页 |
| --- | --- | --- |
| 活动 WPS 文档有幻灯片、未放映、支持启动接口、心跳有效 | 绿色“开始放映”，调用 `SlideShowSettings.Run()` | 使用直接模拟按键 |
| 已接入 WPS 放映 | 红色“结束放映”，调用 `View.Exit()` | `Previous()` / `Next()`，笔迹跟随真实页号 |
| 未接入、联动关闭或断线 | “Esc”，模拟 Escape | 模拟 Up / Down，页号沿用原先的估计方式 |
| 白板 | 背景颜色 | 本地白板页，不发送外部命令 |

只通过 WPS 接口识别待放映，不根据窗口标题或全屏状态猜测，不启动文档列表中任意第一份文件。旧加载项未发送 `ready` 状态时不会显示“开始放映”。START 有防连点、命令有效期和执行前复查；已接入放映但 API 失败时不再额外发键，避免翻两页。

模拟按键使用现有能力：GNOME 扩展虚拟键盘、layer-shell 虚拟键盘或 uinput、原生 X11 XTEST；XWayland 新增 uinput 路径，禁止自动退回会触发 RemoteDesktop 的 XTEST。如果当前桌面没有直接输入能力，上下按钮仍变橙色，不能承诺模拟按键有效。断线期间的估计页在重连后校正为真实页号，保存笔迹时使用当前页，避免错误归入旧页。

## 界面和触摸

- 侧栏、弹窗、菜单、设置、确认框、诊断框与启动画面统一深蓝灰底色，提高文字和边框对比；原有位置、大小和命中区域保持不变。
- 移除鼠标悬浮高亮。按下显示明显填充与亮边，松手后保留 160ms 反馈；不进行缩放、跳动或位置动画。
- 离散按钮在同一按钮内松手后执行，滑出取消；滑条和侧栏拖动仍即时响应。触摸结束正常释放按钮，取消事件清空反馈。
- 一个触点拥有本次 UI 操作，其他手指不重复触发，也不能提前结束滑条；鼠标右键松开不能触发仍按着的左键按钮。
- 颜色选择增加对勾，滑条按住时突出滑块；修正“中 6”标签为实际笔宽“中 5”。

## GNOME 加载错误

用户注销并重新登录后，只读查询发现 `.5` 的扩展为 `ERROR`。Shell 日志明确为 `Meta.is_wayland_compositor is not a function`，并记录用户尝试打开原生入口失败。

GNOME 50 移除了 X11 会话和对应判断接口。扩展版本 2 在旧版本存在该函数时检查，在 GNOME 50 跳过已移除函数。升级已加载或报错的模块需要再次注销、重新登录；安装成功不等于桌面功能已通过。

## 用户操作清单

1. 保存文件，注销并重新登录，启动“Sidera（GNOME 原生）”；重新打开 WPS，使其加载新的脚本。
2. 打开含幻灯片的课件，确认绿色“开始放映”可以启动，随后切为“结束放映”；翻页与结束不弹共享桌面。
3. 关闭 WPS 联动，先点目标窗口取得焦点，再验证上下键和 Esc；返回联动放映后检查原笔迹页。
4. 检查鼠标移过无高亮；按住有反馈，滑出松手取消；快速点按、多指和滑条不重复动作。
5. 画线 → 光标 → 操作下层窗口，复查穿透、闪烁与笔迹保留。
