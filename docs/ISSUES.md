## 绘图、缓存与显示

### S01 — Rust Wayland 初始画布尺寸

初始化必须同时核对逻辑尺寸和实际像素存储。已有画布测试与历史原生 Sway 记录支持修复，不能仅用构造时逻辑尺寸跳过首帧重建。

### S02 — Rust 撤回区域漏乘设备缩放

撤回区域按实际设备缩放向外取整并裁剪。像素测试覆盖画笔、橡皮、边缘及 100/125/150/200%；物理输入体验仍待高 DPI 触屏确认。

### S03 — Rust Wayland 双缓冲写入正在使用的存储

每个帧槽独立持有存储，只写 released 槽，忙时保留待绘内容。两项私有 Wayland 存储检查验证忙槽字节不变、释放后补帧以及旧身份不能释放新槽。

### S04 — C++ Wayland 配置变化未重建缓冲

本轮补齐尺寸/乘法边界与重配置，正在显示的旧 pool 等 release 后回收。不能等待两块旧缓冲全部释放再提交替代画面，否则可能卡住。私有 Sway 的连续尺寸、125%/200% 缩放及 ASan/UBSan 检查通过；真实 4K、多屏拔插仍未验收。

### S05 — 页缓存静默丢失与容量差异

Rust/C++ 均改为无损压缩，单份缓存超过 32 MiB 后写入私有临时目录；失败保留内存并记录错误。45 页强制落盘往返验证包含半透明像素，删除页不复活。预算不是总进程内存上限，退出程序不保留文档。

### S21 — 显示变化与旧缓存

当前笔迹和恢复的旧页适配新尺寸，旧坐标的撤回记录清除。C++ X11 画布重建不再直接丢弃旧图，Wayland resize/scale 已有协议检查。投影仪、旋转和混合 DPI 仍需人工矩阵。

## WPS 与页面状态

### S06 — 重复清空和全屏识别误判

联动模式以加载项状态为准，全屏扫描只承担未联动降级；白板不能被全屏变化清空。短类名使用精确字段匹配，避免 `et` 命中无关窗口。多屏 Office 窗口识别仍需实机确认。

### S07 — 结束放映和重连状态分裂

C++ 两条后端共用完整 Begin/State/End 桥；短时离线保留页位置，重连应用快照，End 清待执行命令。检测到不同文稿标记时开始新的透明批注生命周期。多个加载项流之间尚无权威活动会话，归入 S12。

### S08 — 白板退出缺少状态重同步

白板期间继续记录外部最新页和生命周期，退出时恢复对应透明页；外部 Begin/End 不清白板。Rust 和 C++ 均保留白板独立页码/缓存。真实 WPS 在白板中换页、结束、开始另一份课件仍待用户确认。

### S09 — JS 事件注册不幂等

同一事件接口只注册一次；接口替换后重新注册，旧接口的回调不再发送事件。部分失败按缺失项重试，定时器数量受控。测试不依赖未经验证的宿主解绑 API；真实 WPS 卸载生命周期待验收。

### S10 — JS 状态上报丢失和轮询生命周期缺失

轮询携带快照，失败重试，迟到回复丢弃；状态按钮检查真实 HTTP 响应。新加载项共享 sid/seq 请求序号，桥丢弃该流倒序/重复消息。旧 GET 客户端仍可用，但没有新序号保证；命令最终执行确认尚未实现。

### S11 — WPS 登记存在覆盖和迁移风险

Rust、C++ 与手动安装共用 `wps-addin/install.sh`：结构化 XML 合并、保留其他登记、备份、原子替换和进程锁。自动登记有等待上限。锁只能协调本项目的写入，不能约束 WPS 或第三方外部修改器；部署时仍应退出 WPS。

### S12 — HTTP 会话与资源边界不足

已限制 GET/OPTIONS、请求头/请求行、读取等待、Host/Origin、静态资源白名单、状态事件队列和命令队列。未知静态路径返回 404，静态请求不冒充联动连接；同流序号不回退。

**仍开放**：回环地址和 sid/seq 都不是身份认证；同用户恶意进程、多个加载项争用、旧协议重放、完整放映会话标识和 command_id/执行确认未解决。不要将 16666 转发到外网。后续协议必须兼容实际 WPS，不能仅靠模拟测试直接替换线上格式。

## 平台与输入

### S16 — 截图剪贴板持续性与 Wayland 支持

Rust 已有持久线程、Wayland data-control 和 GNOME Shell PNG 剪贴板路径；XWayland 截图走 Portal。C++ offscreen 后端不能保证桌面剪贴板，现只准确记录 PNG 保存。各桌面向 WPS 粘贴、程序退出后无剪贴板管理器的行为仍需实机验证。

### S17 — Portal 截图请求生命周期

Rust 提前订阅响应、唯一 token、单请求并发、超时关闭与本地 URI 校验已实现；URI 测试已执行。C++ 增加格式/stride/大小校验、超时和 Y 翻转处理。Portal 服务缺失、取消、截图颜色及真实粘贴尚未验收。

### S18 — 能力差异没有产品化表达

Rust 诊断区分 X11、XWayland、layer-shell、GNOME 原生；翻页缺直接输入能力时变橙，不自动请求 RemoteDesktop。历史用户已确认当前 VM 的兼容模式穿透/不闪和早期 WPS 联动；不能推及新版全部原生功能。C++ 不具备同等能力反馈与 UI。

### S19 — 输出、seat 与版本协商

Rust GNOME/layer-shell 共用逐屏 Desktop。C++ bind 取公告版本与支持版本的较小值，按 seat 能力创建/释放输入对象；其当前只处理首个输出/seat，移除所用对象时安全退出，尚不提供完整热插拔恢复或多屏。

### S20 — 触摸取消与停留

Rust 的真正 Cancel、设备/输出移除和首触重绘已处理，不再把静止按住当作松手；C++ 补齐取消和触摸期间鼠标抑制。GNOME 桥没有接触直径数据，不能宣称完成物理面积掌擦。长按、多指及实际触控设备仍待验收。

## 工程与发布

### S13 — 测试误通过和用户目录副作用

C++ 端点测试现在编译真实共用桥，在私有网络和家目录运行，不连接现有服务或 mock。Rust 测试使用临时端口，禁用登记副作用，缺失 manifest 直接失败。统一执行工具不在隔离失败时退回真实会话。

### S14 — Rust arm64 包可含错误架构

打包校验真实 ELF64 小端 EXEC/DYN 与目标机器类型；正向测试使用本机真实可执行文件，拒绝只有头的夹具冒充产物。没有原生 ARM64 应用构建、安装或运行通过结论。

### S15 — C++ 独立桥启停漏停定时器

共用桥停止时清理 timer、server、已接收连接和状态；8 项组件检查包含 100 次启停、端口占用、旧连接、慢请求与析构。该结论不代替整个 Qt 应用的长期泄漏测量。

### S22 — 可复现构建不足

已固定 Rust 1.93.1、locked/offline 构建、LF 脚本、C++ 显式后端及配置变更失效；容器构建记录输入哈希。**仍缺**可校验的 rootfs 初始化/镜像来源；干净检出不能直接运行依赖仓库外 sysroot 的一键脚本。

### S23 — 包依赖与兼容门禁

三个 DEB 入口均用 readelf 与 dpkg-shlibdeps 从实际产物生成依赖，包含真实 QtNetwork/Wayland 等库。打包应在匹配架构和库的构建环境进行；不能手改 libc 要求冒充低 ABI 包。Ubuntu 24.04、麒麟 ARM64 的安装/升级/卸载门禁仍未完成。

### S24 — 配置、字体、单实例和失败反馈

配置拒绝非有限缩放，使用 XDG 路径和原子替换；Rust 旧默认路径可回读。字体按中文字形覆盖选择并验证纯中文渲染。单实例清理受锁保护，socket 唤醒有等待边界。Rust/C++ 仍使用不同实例名；源码自启动、只读目录提示体验及跨实现并行运行仍需单独处理。

### S25 — 性能、内存与时钟

持续时长使用单调时间，页缓存有压缩预算及落盘；仍缺总进程预算、4K/双屏压缩耗时、CPU/输入延迟和长课记录。不可将代码预算或内存错误检查写成性能测量结果。

### S26 — 重复业务和隐含所有权

C++ HTTP/登记桥和页缓存已共用；Rust 分离 Desktop、缓存、HTTP、持久化与实例锁。全局状态、UI/输入控制和跨语言契约仍需渐进整理，按 [重构计划](REFACTOR_PLAN.md) 执行。

### S27 — CI、文档与元数据

CI 配置已覆盖 custom/main、隔离 Rust/JS/C++ 与协议检查，文档统一当前状态和历史记录。远程执行、ARM64/最低系统矩阵未确认。上游 LICENSE 与 Cargo 许可表述差异继续公开说明，未经权利人确认不擅改。

### S28 — 编译打包安装后应用图标不显示

Rust 已在 custom.13 使用随内容变化的图标路径，统一三个入口并保留 desktop ID；文件、入口与用户有效引用曾完成核对。原标志只调整配色。Ubuntu 应用菜单的最终显示、收藏刷新，以及 C++/ARM64 各目标桌面仍按 [G22](TEST_ENVIRONMENT.md#g22-安装后图标专项) 人工验收，不再把根因写为完全未知。
