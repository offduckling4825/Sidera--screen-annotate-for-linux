# Sidera 3.2-Electro.rc.5

**课堂批注 · 白板书写 · WPS 演示联动**

版本：`3.2-Electro.rc.5`（预发布 RC） · 提交：`a96cd3f`

> 本版重点修复 **同一课件多窗口导致放映键乱跳/清空笔迹**、**UKUI/KWin 设置界面模糊**，并加入 **希沃白板 5 避让**。
> 同时修复了发布工作流的 tag 校验，后续 `v3.2-Electro.rc.N` 可直接触发构建。

---

## 重点修复

### 1. 同一 PPT 多窗口导致放映键来回跳、笔迹被清空

- 快速点击文件可能在不同 WPS 窗口打开同一课件，其中一个进入只读；多个加载项同时向桥上报状态，导致“开始放映/结束放映”反复切换并清空画布。
- 加载项现在为每个实例上报 `sid`，桥只接受**正在放映窗口**的状态。
- 只读/重复窗口上报的结束或旧页码会被标记为 passive，不能结束或跳转当前页。
- `EXIT` / `START` 指令若被错误的窗口取走并失败，会自动重试，避免退出放映丢失。

### 2. UKUI / KWin X11 设置界面模糊

- 设置窗口现在请求 `_NET_WM_BYPASS_COMPOSITOR=2`，尝试让 KWin 跳过该窗口的合成缩放/模糊。
- 保留 rc.4 的像素对齐（1px 线条、文字原点）。
- 新增/保留诊断开关：
  - `SIDERA_DUMP_SETTINGS=/tmp/settings.png`：导出设置窗口实际绘制画面。
  - `SIDERA_SETTINGS_OVERLAY=1`：强制用覆盖层绘制设置，用于对比。
  - `SIDERA_SETTINGS_KEEP_COMPOSITOR=1`：关闭 bypass，做对照测试。
- 若本版仍模糊，请把 dump 的 PNG 与覆盖层效果发回，可判断是合成器还是字体栅格化问题。

### 3. 希沃白板 5 避让（X11）

- 检测 `WM_CLASS=easinote` 的可见、非最小化窗口。
- 进入希沃白板时：自动收起侧边栏、隐藏侧栏、清空导航输入区域，无法再打开。
- 退出或最小化后：立即恢复并强制展开侧边栏，无论之前是否手动收起。
- 当前为 X11 实现；原生 Wayland 下暂不生效。

### 4. Wayland 启动界面分辨率

- 启动卡片“桌面连接”改为显示**物理分辨率**（逻辑尺寸 × 缩放比例），不再显示缩放后的逻辑值。

### 5. 发布工作流修复

- `release.yml` / `release-arm64.yml` 的 tag 校验支持 `v3.2-Electro.rc.N`。
- `tools/release_metadata.py` 同时接受旧 `custom` tag 和新的 rc tag。
- release 触发改为 `v3.2-Electro.rc.*`，后续 rc 版本无需再改 workflow。

## 安装

### Debian / Ubuntu / Deepin / UOS

```sh
sudo apt install ./sidera_3.2-Electro.rc.5_amd64.deb   # amd64
sudo apt install ./sidera_3.2-Electro.rc.5_arm64.deb   # arm64
```

### Fedora / openSUSE 等 RPM 系

```sh
sudo dnf install ./sidera-3.2-Electro.rc.5.x86_64.rpm
```

### Arch Linux

```sh
sudo pacman -U ./sidera-3.2_electro_rc_5-1-x86_64.pkg.tar.zst
```

### Windows

1. 解压 `sidera-windows-x64.zip`。
2. 运行 `sidera.exe`。
3. WPS 加载项位于 `wps-addin/`，中文字体位于 `fonts/`。

## 已知说明

- 本版为**预发布 RC**，建议先在非关键课堂环境试用。
- 设置窗口若仍发虚：请用 `SIDERA_DUMP_SETTINGS` 导出 PNG，并与 `SIDERA_SETTINGS_OVERLAY=1` 的覆盖层效果对比。
- 希沃白板避让目前仅 X11；原生 Wayland 下不检测。
- Ctrl+P 依赖 `/dev/input` 读权限；evdev 不可用时 X11/XWayland 会回退到抓键。
- 原生 Wayland 下的 WPS 指针复位依赖加载项的 `PointerType` 写入能力；失败会写入诊断日志。
- C++/Qt5 legacy 版未包含本版修复；安装包为 Rust 实现。
- 白板笔迹退出程序后不持久保存（与既有设计一致）。
