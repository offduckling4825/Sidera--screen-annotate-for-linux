# Sidera 3.2-Electro.rc.4

**课堂批注 · 白板书写 · WPS 演示联动**

版本：`3.2-Electro.rc.4`（预发布 RC） · 提交：`37c32bd`

> 本版重点修复 **X11 / UKUI 设置界面发虚** 与 **Ctrl+P 画笔快捷键**，并同步 Windows。
> 设置界面线条和文字在整数缩放下按设备像素对齐；Ctrl+P 改为内核 evdev 识别，只有真实快捷键才切换 Sidera。

---

## 重点修复

### 1. 设置界面线条与文字发虚

- 1px 横向/纵向线条吸附到设备像素中心，消除“灰糊线”。
- 整数缩放下文字原点吸附到整像素，小字号中文更清晰。
- 新增诊断开关：
  - `SIDERA_SETTINGS_OVERLAY=1`：强制用覆盖层绘制设置，方便对比。
  - `SIDERA_DUMP_SETTINGS=/tmp/settings.png`：导出设置窗口实际画面。
- 诊断面板会记录原生/覆盖层路径、缩放比例与窗口尺寸。

### 2. Ctrl+P 画笔快捷键（跨 X11 / XWayland / Wayland）

- 改用内核 **evdev** 监听物理 Ctrl+P，不依赖 X11 grab，也不受 niri 等 Wayland 合成器限制。
- **只有真实快捷键**才切换 Sidera；手动点 WPS 画笔不会触发。
- 切换后通过 WPS 加载项新增的 `CURSOR` 指令，把 WPS 指针复位为光标，避免光标模式下穿透画出 WPS 墨迹。
- X11/XWayland 保留抓键作为兜底；Windows 继续使用 `RegisterHotKey`。
- 需要 `/dev/input` 读权限（DEB 已带 uaccess 规则；源码运行需在 `input` 组）。

### 3. 默认画笔与橡皮尺寸

- 默认画笔：**5px**
- 默认橡皮：**60px**
- 已加回归测试。若旧配置中保存过 `eraserSize=1`（30px），会保留你的历史选择，不会被默认值覆盖。

## 安装

### Debian / Ubuntu / Deepin / UOS

```sh
sudo apt install ./sidera_3.2-Electro.rc.4_amd64.deb   # amd64
sudo apt install ./sidera_3.2-Electro.rc.4_arm64.deb   # arm64
```

### Fedora / openSUSE 等 RPM 系

```sh
sudo dnf install ./sidera-3.2-Electro.rc.4.x86_64.rpm
```

### Arch Linux

```sh
sudo pacman -U ./sidera-3.2_electro_rc_4-1-x86_64.pkg.tar.zst
```

### Windows

1. 解压 `sidera-windows-x64.zip`。
2. 运行 `sidera.exe`。
3. WPS 联动加载项位于 `wps-addin/`，中文字体位于 `fonts/`。

## 已知说明

- 本版为**预发布 RC**，建议先在非关键课堂环境试用。
- 设置界面若仍发虚：请用 `SIDERA_DUMP_SETTINGS` 导出 PNG，并与 `SIDERA_SETTINGS_OVERLAY=1` 的覆盖层效果对比。
- Ctrl+P 依赖 `/dev/input` 读权限；若诊断面板显示“evdev 不可用”，X11/XWayland 会自动回退到抓键。
- 原生 Wayland 下的 WPS 指针复位依赖 WPS 加载项的 `PointerType` 写入能力；失败会写入诊断日志。
- C++/Qt5 legacy 版未包含本版修复；安装包为 Rust 实现。
- 白板笔迹退出程序后不持久保存（与既有设计一致）。
