# Sidera 3.2-Electro-rc.2

**课堂批注 · 白板书写 · WPS 演示联动**

版本：`3.2-Electro-rc.2`（预发布 RC） · 提交：`303c5ce`

> 本版是 **Rust 主力版**与 **Windows 版**的同步修复版本，重点解决课堂使用中反馈的 5 个问题。
> **C++/Qt5 legacy 版未包含这些修复**，安装包为 Rust 实现。

---

## 重点修复

### 1. 侧边栏收缩后再展开，画笔组状态错误

- 画笔模式下收起侧边栏，再展开时，即使画布上已有笔迹，画笔组仍保持收起。
- 现在展开侧边栏会**按画布实际笔迹自动恢复**画笔组；空白页仍保持收起。

### 2. 新增更细的画笔与橡皮档位

- 画笔：`2 / 3 / 5 / 10`（新增 **2px**）
- 橡皮：`20 / 30 / 60 / 80`（新增 **20px**）
- 旧配置中的橡皮档位索引会**自动迁移**，不会因新增档位而改变实际选择。

### 3. 修复 UKUI / X11 下设置界面发虚

- 在 UKUI 桌面、X11 会话、100% 缩放下，设置界面出现模糊。
- 现在缩放检测会**吸附接近整数的 DPI 噪声值**，并让设置窗口**复用覆盖层的权威缩放**，避免无意义的分数缩放。
- 同时兼容 `QT_SCALE_FACTOR`、`GDK_SCALE`、`GDK_DPI_SCALE` 与 `Xft.dpi`。

### 4. 进程屏蔽 / 运行日志 / 系统诊断翻页动画

- 三个面板的翻页由瞬间跳变改为 **140ms 滑动动画**。
- 列表与页面内容平滑移动，滚动位置与命中区域仍即时生效。

### 5. 设置窗口最小化后侧边栏不可用

- 设置窗口最小化时，覆盖层仍把它当作前台窗口，导致侧边栏无法操作。
- 现在**最小化视作关闭设置界面**，立即恢复侧边栏输入区域。
- X11 通过 `WM_STATE` / `_NET_WM_STATE_HIDDEN` 判断，Windows 通过 `SIZE_MINIMIZED` 判断。

- **移除“右键切回光标”功能**及相关设置项、配置项和各后端右键注入代码。
  - 画笔/橡皮模式下，鼠标右键不再切换到光标模式。

## 安装

### Debian / Ubuntu / Deepin / UOS

```sh
# amd64
sudo apt install ./sidera_3.2-Electro-rc.2_amd64.deb

# arm64
sudo apt install ./sidera_3.2-Electro-rc.2_arm64.deb
```

### Fedora / openSUSE 等 RPM 系

```sh
sudo dnf install ./sidera-3.2-Electro.rc.2.x86_64.rpm
```

### Arch Linux

```sh
sudo pacman -U ./sidera-3.2_electro_rc_2-1-x86_64.pkg.tar.zst
```

### Windows

1. 解压 `sidera-windows-x64.zip`。
2. 运行 `sidera.exe`。
3. 如需 WPS 联动，将压缩包内 `wps-addin/` 加载项安装到 WPS（详见包内 `README.txt`）。
