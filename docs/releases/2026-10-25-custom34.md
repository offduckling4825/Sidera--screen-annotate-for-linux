## 本版内容

- 全界面浅色、深色、跟随系统：工具栏、弹窗、设置、启动页、动画、多屏和交互状态共同切换，并保存偏好。详情与预览见[主题说明](../DARK_MODE.md)。
- **白板底色保持原来的白色／绿板**，不会随界面主题改变；实际笔迹、页缓存和撤回内容不做反色处理。
- 包含此前 `.30`–`.33` 的页缓存切换、状态保存、WPS 桥、Wayland 缓冲和隔离检查修复，详见[更新记录](../../CHANGELOG.md)。
- amd64 与 ARM64 同版本发行，均使用原生 Ubuntu 22.04 构建环境，实际库依赖从 ELF 推导。构建流程见[双架构工作流](../../.github/workflows/release.yml)。

## 验证范围

发布工作流分别在原生 amd64、ARM64 上执行普通 Rust 用例（包含主题检查）、私有 Xvfb、私有 Sway 及包内二进制的启动诊断检查；同时核对源码标签、锁文件、包版本、真实 ELF 架构和提取后的主程序，并模拟依赖解析。仅成功任务生成发布附件，各次实际通过数、运行链接与哈希见对应架构的 `BUILDINFO` 和测试日志。

真实 VMware / ARM 桌面、触摸设备和 WPS 的交互仍由用户验收；未代做桌面操作。Ubuntu 22.04 是构建基线，不表示 GNOME 42 已获得原生扩展支持：配套扩展元数据仍声明 GNOME 46–50。学校麒麟 ARM64 / glibc 2.31 环境仍需要更低基线构建与实机验证。白板退出程序后不持久保存，安装包不包含 WPS 或系统 Xwayland 修补包。

此前 `.33` 本地包已在 VMware Ubuntu 26.04.1 安装核对，但不能把旧包安装记录当成本次低基线包已完成全部安装验收。原记录保留在[主题说明](../DARK_MODE.md)；`.29` 的原 amd64 文件与其 ARM64 补充也继续保留在历史 Release。
