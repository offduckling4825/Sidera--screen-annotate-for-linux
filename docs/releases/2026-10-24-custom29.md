## 构建来源与重建

源代码为此 tag 的仓库内容，Rust 依赖由 `rust/Cargo.lock` 固定。此次二进制在对应环境中通过：

release 另外提供 `Sidera-custom20261024.29-source-with-dependencies.tar.gz`，包含此提交的源码、锁定的 Cargo 依赖及离线依赖配置；已安装 Rust 和系统编译工具的 Linux 环境可解压后进入 `Sidera-custom20261024.29/rust/`，使用 `cargo build --release --locked --offline` 构建。归档不包含 Rust 工具链、系统库或 WPS。

```sh
cd rust
cargo check --tests --examples --locked
cargo build --release --locked
```

本地打包副本沿用 `rust/build_deb.sh`，仅将以下两处发布元数据调整为：

```text
VERSION="3.0-Electro-testing+custom20261024.29"
Depends: libc6 (>= 2.43), libgcc-s1, python3
```

确认选中的是本次 `target/release/sidera`，而非旧的 `target/container-amd64` 产物，再执行 `bash build_deb.sh amd64`。其他系统编译时应根据 ELF 实际版本需求声明依赖，不能照抄本机值。此说明是来源与构建流程记录，不承诺不同机器构建逐字节一致。
