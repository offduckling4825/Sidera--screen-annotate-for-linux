# Sidera 学校 U 盘安装与恢复

为学校报告中的银河麒麟 V10 SP1、飞腾 D2000、ARM64、UKUI X11、glibc 2.31 准备。原机已有 Sidera 2.6；本工具采用**用户目录并存安装**，不会用 DEB 覆盖原包。

## 使用

在 U 盘的 `Sidera_Installer` 文件夹空白处右键，选择“在终端中打开”，执行：

```sh
bash ./start.sh
```

选 `1` 完全离线安装或更新。安装完成后，从应用菜单打开 **Sidera 课堂新版**。不要使用 `sudo`，不要手工安装 U 盘 `packages` 内的 DEB。所有入口、文件夹和报告文件名使用英文，菜单和说明保留中文。

应用菜单还有 **Sidera 原版（保留）** 与 **Sidera 安装与恢复**。原来的 Sidera 图标保持原样。新版启动前需要先正常退出原版，保留需要的批注；工具不会强制结束应用。

## 更新与备用路径

1. 全程不查询网络、不下载、不调用 apt 安装依赖。按版本从新到旧检查 U 盘内对应架构的包，并校验 SHA256。
2. 检查包信息、实际 ELF 架构、glibc 符号及动态加载依赖；不运行 DEB 安装脚本，不安装或升级系统库。
3. 优先使用 ARM64 旧系统兼容构建；副本损坏时尝试备用副本。标准 ARM64 custom.35 需要 glibc 2.34，不能在学校的 2.31 上直接使用。
4. 完整解包和依赖检查通过后才切换所选新版；此前版本及原版备份保留。不会自动降级已安装的较新版本。
5. 新版异常退出时，在原生 X11 会话下自动退回原版；正常退出不会触发回退。一直卡住或功能异常无法由退出码识别，请正常退出新版，再选“启动原版”或“切回原版”。

盘内最新软件为含深色模式的 custom.35。以后要更新，请在有网的电脑重新准备整套 U 盘；学校电脑不会等待联网或尝试从网上获取新版。

## 保留与恢复

- 原版系统文件、原配置和应用入口不被覆盖。首次安装前备份原包可读取文件及相关配置，校验主程序；U 盘可写时再保存一份副本。
- 新版位于 `~/.local/share/sidera-usb/versions`，设置、缓存、WPS 自动登记和启动错误放到独立 profile。
- U 盘安装后可拔走，已安装程序及字体位于本机。运行恢复入口不依赖 U 盘。
- 默认保留原自启动，新版手动运行；自启动的接管与恢复见下节。
- “切回原版”会恢复原自启动设置，不卸载程序、删除配置或强制关闭窗口。再次安装或选择新版自启可重新选择新版。
- 本工具不改动 WPS 本体。默认保留原 WPS 登记，未接入时按应用能力模拟翻页按键；需要完整联动，关闭 WPS 后选 `6`。登记前先保存可恢复记录，回退时恢复 Sidera 条目并保留其他加载项。
- 日志和备份包含版本、文件路径及相关配置，不采集课件正文、屏幕截图、密码。不要公开上传整个备份目录。

## 自启动只选一个版本

- 默认安装不改变旧版自启动，也不增加新版自启动；新版设置中的开关初始关闭。
- 菜单选 `7`，或在通过工具启动的新版中打开“开机自启动”：备份旧入口，以用户级 `Hidden=true` 停用旧版的 XDG 桌面自启，启用唯一的 `sidera-usb-managed.desktop`。系统目录不被改写。
- 接管后，关闭新版开关或菜单选 `8`，两版均不自启，旧入口保持停用；不会悄悄重新启用旧版。未接管时选 `8` 不改变旧版。
- 菜单选 `9`、切回/启动原版或新版异常回退，会撤回新版入口，按备份还原原入口的内容和权限；原先未开启的旧版自启也不会被凭空开启。
- 新版运行时，管理器检查私有开关并同步真实入口；正常退出前再同步一次。切换中断保留事务记录，下次运行会恢复未完成的变更。
- 其他软件的入口保持不变；发现外部修改、符号链接或同名冲突时拒绝覆盖并记录原因。此机制管理 XDG 桌面自启动；管理员另配的系统服务、计划任务或登录脚本不在接管范围内。

入口优先级与停用方式遵循 [Freedesktop 自启动规范](https://specifications.freedesktop.org/autostart/latest/)。自启动备份在本机 `autostart-journal.json`，U 盘可写时同步到 `backups`。不要手工同时启用旧入口和新版入口；请通过同一个管理器切换。

## 日志报告

每次执行生成文字、HTML、JSON 报告及程序输出。包含环境、候选包选择/拒绝原因、校验、依赖检查、进程退出码、是否回退和人工未验收项。

- 本机：`~/.local/share/sidera-usb/logs/时间编号/`。
- U 盘：`Sidera_Installer/logs/时间编号/`。
- 拔盘期间先记在本机，插回 U 盘再执行检测会补拷记录。U 盘只读/满盘时，明确提示并保留本机报告。
- `backups` 是原版备份，不是安装包；不要删除或手工覆盖系统。

## 构建与验证

ARM64 兼容构建使用 custom.35 原始源码和锁定依赖，Rust 1.93.1、cargo-zigbuild 0.20.1、Zig 0.14.1，目标 `aarch64-unknown-linux-gnu.2.31`。方法依据 [cargo-zigbuild 官方说明](https://github.com/rust-cross/cargo-zigbuild#specify-glibc-version)，最终以 ELF 版本检查和实际旧库启动结果为准，不能只相信目标参数。

U 盘 `records` 保存构建来源、实际校验值、ARM64 + glibc 2.31 的隔离模拟检查与安装器测试记录。中文字体独立附带 Noto Sans CJK，许可随字体分发。对应源码、原项目署名及第三方许可随 U 盘保存。

本机运行安装器回归检查：

```sh
python3 tools/run_isolated.py --timeout 180 -- python3 tools/usb-kit/test_usb_kit.py
```

检查使用临时 HOME、私有网络和 `/bin/true`、`/bin/false` 测试夹具，不启动真实 Sidera、WPS 或用户桌面。ARM64 的启动验证使用 QEMU、Ubuntu 20.04 的 glibc 2.31 与私有 Xvfb。**这不等于在学校飞腾硬件上完成了透明、穿透、触控和 WPS 验收。**

安装器能避免覆盖原版，但不能保证磁盘故障、原系统已损坏或原版自身问题时仍一定能运行。请保留原版入口，实际课堂使用前试写、切光标、翻页和白板。
